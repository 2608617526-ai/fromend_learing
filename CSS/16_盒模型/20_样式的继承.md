## 哪些会继承？
字体，文本，还有visibility会继承（display）不继承

空间排版，外观不会继承，
border，backgruoud

有些特殊的标签自带样式，不会继承，比如<a>自带蓝色和下划线，还有<h2>自带粗体和字号。
其实还有，ul（列表表单类，有黑点），body（自动带了8px的外边距），决定的

同时css还提供了一个继承关键字：inherit
你只需要把子元素的某个属性设置为inherit,它就会强行去抄父元素的作业，哪怕是<a>标签和h标签
``` css
div {
    color: red;
}

/* 强行抹杀 a 标签的默认蓝色，让它去继承父盒子的红色 */
div a {
    color: inherit; 
    text-decoration: none; /* 顺手干掉下划线 */
}
